# Сервер — установка и обновления

Один раз настраиваем, дальше код обновляется сам каждые 5 минут из git.

## Что должно быть установлено

Проверяй командами в PowerShell или cmd:

```
java -version       # 21.x
mvn -version        # 3.8+
node -v             # 18+
git --version
psql --version      # 16.x
```

Если все 5 команд работают — всё в порядке. Логин/пароль PostgreSQL — `postgres` / `postgres` (стандарт после установки).

## Установка (один раз)

1. Открой PowerShell или cmd, перейди куда хочешь хранить код (например, `C:\carpet`).
2. Клонируй репо:
   ```
   git clone <ссылка-на-репо> .
   ```
3. **Запусти от имени администратора** *(правый клик → «Запуск от имени администратора»)*:
   ```
   deploy\setup.bat
   ```

Скрипт сделает всё:
- проверит инструменты,
- создаст БД `carpet_db`,
- соберёт фронт + бэк в один jar,
- зарегистрирует задачу авто-обновления (Task Scheduler, каждые 5 минут),
- запустит приложение.

В конце увидишь: `READY. Open http://localhost:8080`.

**Логин:** `admin` / `foxy`. После первого входа создай новых пользователей в разделе «Пользователи» (видно супервизору).

## Что обновляется само

Раз в 5 минут Task Scheduler запускает `deploy\update.bat`:
1. `git pull` — если коммитов нет, тихо выходит.
2. Если код обновился — пересобирает фронт + бэк.
3. Перезапускает приложение.

Лог: `deploy\update.log`.

## Команды на каждый день

| Что | Команда |
|---|---|
| Посмотреть логи приложения | `type deploy\app.log` |
| Посмотреть логи обновлений | `type deploy\update.log` |
| Перезапустить | `deploy\stop.bat` потом `deploy\start.bat` |
| Обновить вручную (не ждать 5 мин) | `deploy\update.bat` |
| Полностью удалить (без БД) | `deploy\uninstall.bat` |

## Доступ извне (если нужно)

По умолчанию приложение слушает `localhost:8080` — открыто только с самого сервера.

Чтобы открыть на ЛВС или интернет:
1. **Брандмауэр Windows:** разреши входящие на TCP 8080.
2. **Роутер:** проброс порта 8080 → IP сервера.
3. **DDNS / белый IP:** если хочешь по доменному имени — настрой DDNS у провайдера.

## Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| `setup.bat` падает на `mvn package` | Проверь `mvn -version`. |
| БД не создаётся | Проверь что PostgreSQL запущен (`services.msc` → PostgreSQL). Пароль `postgres`/`postgres`. |
| Приложение не открывается на 8080 | `netstat -ano \| findstr :8080`. Перезапусти `deploy\stop.bat` → `deploy\start.bat`. |
| Авто-обновление не работает | Открой Task Scheduler, найди задачу `CarpetOrdersAutoUpdate`. Запусти руками для проверки. |
| Не пускает после обновления | `deploy\update.log` — там видно что упало при последнем билде. |

## Файлы конфигурации

Всё в репо, на сервере править ничего не нужно. Если хочешь изменить — поменяй у себя и закоммить, авто-апдейт подхватит.

- `backend/src/main/resources/application-prod.yml` — настройки бэкенда (БД, порт, дефолтный логин)
- `deploy/setup.bat` / `update.bat` / `start.bat` / `stop.bat` — все скрипты
- `backend/src/main/resources/db/migration/V*.sql` — миграции БД (накатываются автоматически)

## Переопределение через env-переменные

Если на сервере специфичные настройки (другой пользователь БД, другой порт), задай в **переменных среды Windows**:

| Переменная | По умолчанию |
|---|---|
| `SPRING_DATASOURCE_URL` | `jdbc:postgresql://localhost:5432/carpet_db` |
| `SPRING_DATASOURCE_USERNAME` | `postgres` |
| `SPRING_DATASOURCE_PASSWORD` | `postgres` |
| `APP_ADMIN_USERNAME` | `admin` |
| `APP_ADMIN_PASSWORD` | `foxy` |
| `SERVER_PORT` | `8080` |

Эти переменные подставляются Spring'ом автоматически (см. `application-prod.yml`). Менять `.yml` под прод не нужно.
