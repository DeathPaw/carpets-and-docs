## Утверждённые бизнес-правила из памяти Claude

- Цена заказа берётся из версии SKU на `orders.price_date` (дата оформления).
  Пересчёт по текущему прайсу — явное действие. Корректировки размеров и
  материала из производства используют текущий прайс и пишутся в историю
  корректировок.
- ФОТ округляется у месячного итога сотрудника математически до 100 ₽,
  половина вверх. Сумма заказа округляется вниз до 100 ₽ — это другое правило.
- Расход, попавший в два месяца, распределяется по фактическим метрам месяца.
  База себестоимости — обработанные метры по дате завершения обработки;
  окладный и сменный ФОТ распределяются по ней же.
- Контрактный факт наступает при сдаче ковра или завершении выездной чистки.
- Смену оператора определяют по активности в `audit_log.actor` за день с
  возможностью ручной корректировки.
- В Excel-импорте оператор явно выбирает режим обновления, сопоставление
  по умолчанию — по внешнему ID. Повторная загрузка не создаёт дублей.
- Авторизация по ролям `SUPERVISOR`, `ADMIN`, `OPERATOR`, `READONLY`;
  мобильные работники входят по PIN. Статус заказа и автоуслуги связаны
  полями lifecycle SKU, правила переходов проверяются в сервисе.
