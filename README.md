# Система учёта заказов — Производство ковров

Веб-приложение для управления заказами, клиентами, позициями, услугами и сотрудниками с полным циклом от создания заказа до выполнения услуг.

## Основные возможности

### 🏢 Управление заказами
- Создание заказов с привязкой к клиентам (существующим или новым)
- Отслеживание статусов заказов (Лид → Создан → В работе → Готов → Доставлен)
- Управление позициями заказа с различными типами изделий
- Система оплаты и гарантийные возвраты

### 👥 Управление клиентами
- Полная база клиентов с контактными данными (имя, телефон, email, адрес)
- История заказов каждого клиента
- Создание новых клиентов при оформлении заказа с заполнением всех полей

### 🛠️ Управление услугами
- Гибкая система услуг, привязанных к типам позиций
- Ручное добавление услуг к каждой позиции заказа (без автоматического добавления)
- Назначение исполнителей на конкретные услуги
- Отслеживание статуса выполнения услуг

### 👷 Управление сотрудниками
- База сотрудников с контактной информацией
- Просмотр назначенных услуг для каждого сотрудника
- Фильтрация услуг по статусу выполнения
- Переход к деталям заказа из списка услуг сотрудника

### 📋 Справочники
- Управление типами позиций (Ковер, Палас, Дорожка и т.д.)
- Управление услугами (Стирка, Глажка, Ремонт и т.д.)
- Привязка доступных услуг к типам позиций

## Установка

### 1. PostgreSQL

Установить PostgreSQL (если не установлен):
```bash
# macOS (Homebrew)
brew install postgresql@16
brew services start postgresql@16

# Ubuntu/Debian
sudo apt install postgresql postgresql-contrib
sudo systemctl start postgresql
```

Создать базу данных:
```bash
psql -U glebramazanov -d postgres -c "CREATE DATABASE carpet_db;"
```

Применить схему БД:
```bash
psql -U glebramazanov -d carpet_db -f backend/src/main/resources/schema.sql
```

### 2. Java / Maven

```bash
# macOS (Homebrew)
brew install openjdk@21 maven

# Ubuntu/Debian
sudo apt install openjdk-21-jdk maven
```

### 3. Node.js

```bash
# macOS (Homebrew)
brew install node

# Ubuntu/Debian
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install nodejs

# Или через nvm (рекомендуется)
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
nvm install 20
nvm use 20
```

## Настройка

### Бэкенд

Отредактировать `backend/src/main/resources/application.yml`:
```yaml
spring:
  datasource:
    url: jdbc:postgresql://localhost:5432/carpet_db
    username: glebramazanov   # ваш системный пользователь PostgreSQL
    password:                 # пустой если без пароля
```

### Фронтенд

По умолчанию фронтенд обращается к `http://localhost:8080`.
Чтобы изменить адрес бэкенда, создать файл `frontend/.env`:
```
VITE_API_BASE_URL=http://localhost:8080
```

## Запуск

### Бэкенд
```bash
cd backend
mvn spring-boot:run
```
Бэкенд запустится на `http://localhost:8080`

### Фронтенд
```bash
cd frontend
npm install      # только при первом запуске
npm run dev
```
Фронтенд запустится на `http://localhost:3000`

## Основные экраны системы

### 📋 Заказы (`/orders`)
- Список всех заказов с фильтрацией по статусу
- Создание новых заказов с выбором/созданием клиента
- Переход к детальному просмотру заказа (клик по строке)

### 🔍 Детали заказа (`/orders/:id`)
- Полная информация о заказе и клиенте
- Управление позициями заказа
- Добавление и управление услугами для каждой позиции (ручное добавление)
- Назначение исполнителей на услуги
- История изменений статуса

### 👥 Клиенты (`/clients`)
- База всех клиентов с полными контактными данными
- Просмотр истории заказов клиента
- Создание и редактирование клиентов

### 👷 Сотрудники (`/employees`)
- Управление базой сотрудников
- Просмотр назначенных услуг для каждого сотрудника
- Фильтрация услуг по статусу
- Переход к заказу через кнопку "Подробнее"

### 📚 Справочники (`/references`)
- Управление типами позиций
- Управление услугами
- Настройка привязки услуг к типам позиций

### 📊 Позиции (`/items`)
- Фильтрация позиций по различным критериям
- Массовые операции с позициями

### 📝 Лог ошибок (`/error-log`)
- Мониторинг системных ошибок
- История ошибок с детальной информацией

---

## Рабочий процесс

1. **Настройка справочников**: Создайте типы позиций и услуги, настройте их связи
2. **Управление клиентами**: Добавьте клиентов или создавайте их при оформлении заказов
3. **Создание заказов**: Оформляйте заказы, добавляйте позиции нужных типов
4. **Добавление услуг**: Для каждой позиции вручную добавляйте необходимые услуги
5. **Назначение исполнителей**: Назначайте сотрудников на конкретные услуги
6. **Отслеживание прогресса**: Обновляйте статусы услуг и позиций по мере выполнения
7. **Завершение заказа**: Переводите заказ в статус "Готов" и оформляйте оплату

## API

Базовый URL: `http://localhost:8080`

| Метод | Путь | Описание |
|-------|------|----------|
| GET/POST | `/api/orders` | Список / создание заказов |
| GET | `/api/orders/{id}` | Детали заказа |
| PATCH | `/api/orders/{id}/status` | Изменить статус |
| POST | `/api/orders/{id}/pay` | Оплатить заказ |
| POST | `/api/orders/{id}/warranty` | Гарантийный возврат |
| GET | `/api/orders/{id}/history` | История изменений статуса |
| GET/POST | `/api/orders/{id}/items` | Позиции заказа |
| GET/POST | `/api/orders/{id}/items/{itemId}/services` | Услуги позиций |
| GET/POST/PUT | `/api/clients` | Управление клиентами |
| GET | `/api/clients/{id}/orders` | Заказы клиента |
| GET/POST/PUT/DELETE | `/api/employees` | Сотрудники |
| GET | `/api/employees/{id}/services` | Услуги сотрудника |
| GET | `/api/items` | Фильтрация позиций |
| GET | `/api/order-items/{id}` | Получение позиции по ID |
| GET | `/api/services` | Фильтрация услуг |
| GET/POST/PUT/DELETE | `/api/item-types` | Типы позиций |
| GET/POST/PUT/DELETE | `/api/service-definitions` | Шаблоны услуг |
| GET | `/api/error-log` | Лог ошибок |
